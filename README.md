Personal Portfolio Website

Overview
A personal portfolio website developed from scratch using HTML and CSS in Year 12 while learning web development as part of my A-Level studies. This project allowed me to apply my knowledge in a practical setting 
and build a website to showcase my background, achievements, and interests.

Content:
- Custom Design: Built using HTML and CSS, providing hands-on experience with website structure, styling, and layout.
- CV: Showcases my education, skills, and experience.
- Projects: Highlights personal projects and practical programming experience.
- Personal Statement: Outlines my academic interests and ambition to pursue a career in software engineering.

Future Development
Since launching the website, I have continued to develop my technical skills and work on more advanced projects. I plan to revisit and improve the website to reflect my academic progress,
expand the projects section, update my CV, and incorporate the knowledge and experience I have gained through further software development.

This project represents an early milestone in my journey towards becoming a software engineer and will continue to evolve alongside my skills and experience.
